# 📹 Apsny Camera Recorder

Веб-приложение для непрерывной записи видео с камер https://apsny.camera/ с автоматическим обновлением токенов.

## 🎯 Проблема и решение

**Проблема:** При записи видео с камер apsny.camera токен доступа истекает через определённое время, что прерывает запись.

**Решение:** Это приложение автоматически отслеживает время жизни токена и обновляет его перед истечением, обеспечивая непрерывную запись без прерываний.

## ✨ Основные функции

- ✅ **Автоматическое обновление токена** - отслеживание и обновление токена до истечения срока действия
- ✅ **Непрерывная запись** - запись продолжается даже при обновлении токена
- ✅ **Поддержка HLS потоков** - работа с .m3u8 потоками
- ✅ **Мониторинг в реальном времени** - отображение статуса соединения и времени до истечения токена
- ✅ **Настройка качества** - выбор качества записи (высокое/среднее/низкое)
- ✅ **Множественные записи** - возможность сохранять несколько записей
- ✅ **Журнал событий** - детальное логирование всех операций
- ✅ **Адаптивный дизайн** - работает на десктопе и мобильных устройствах

## 🚀 Быстрый старт

### Способ 1: Прямое открытие в браузере

1. Откройте файл `index.html` в современном браузере (Chrome, Firefox, Edge)
2. Введите ID камеры (например: `sukhum_chegem`)
3. Нажмите "Загрузить поток"

### Способ 2: Локальный веб-сервер (рекомендуется)

```bash
# С помощью Python 3
cd video-recorder
python3 -m http.server 8000

# С помощью Node.js (npx)
npx http-server -p 8000

# С помощью PHP
php -S localhost:8000
```

Затем откройте браузер и перейдите на `http://localhost:8000`

## 📖 Инструкция по использованию

### Шаг 1: Получение Stream URL (если автоматически не получается)

1. Откройте https://clients.apsny.camera/ в браузере
2. Откройте DevTools (F12)
3. Перейдите на вкладку **Network**
4. В поле фильтра введите `m3u8`
5. Выберите камеру для просмотра на сайте
6. В списке Network запросов найдите файл `.m3u8`
7. Скопируйте полный URL (правый клик → Copy → Copy URL)
8. URL будет выглядеть примерно так:
   ```
   https://stream.apsny.camera/hls/sukhum_chegem/index.m3u8?token=eyJhbGc...
   ```

### Шаг 2: Загрузка потока

**Автоматический способ:**
1. Введите ID камеры (например: `sukhum_chegem`)
2. Нажмите "Загрузить поток"
3. Приложение попытается автоматически получить stream URL и токен

**Ручной способ (если автоматический не работает):**
1. Следуйте инструкциям из Шага 1
2. Вставьте полученный URL в поле "Stream URL"
3. Токен будет извлечён автоматически из URL

### Шаг 3: Запись видео

1. После успешной загрузки потока видео должно начать воспроизводиться
2. Выберите качество записи (Высокое/Среднее/Низкое)
3. Нажмите кнопку **"Начать запись"** (красная кнопка с ⏺)
4. Запись начнётся, вы увидите:
   - Красный индикатор записи
   - Таймер записи
   - Текущий размер файла
5. Для остановки нажмите **"Остановить запись"** (⏹)

### Шаг 4: Автоматическое обновление токена

Приложение автоматически:
- Отслеживает время до истечения токена
- Обновляет токен за 2 минуты до истечения
- Продолжает запись без прерывания
- Показывает количество обновлений токена

**Настройки:**
- ✅ "Автоматически обновлять токен" - включить/выключить автообновление
- 🔄 "Обновить токен вручную" - принудительное обновление

### Шаг 5: Управление записями

После остановки записи:
1. Запись появится в разделе **"Записи"**
2. Для каждой записи доступно:
   - **⬇ Скачать** - сохранить видео на компьютер (формат WebM)
   - **🗑 Удалить** - удалить запись из списка
3. Кнопка **"Очистить все"** - удалить все записи

## 🔧 Технические детали

### Поддерживаемые форматы

- **HLS (HTTP Live Streaming)** - .m3u8 плейлисты
- **Прямые видео URL** - MP4, WebM и другие форматы
- **Токенизированные потоки** - автоматическое извлечение и обновление токенов

### Качество записи

| Уровень | Битрейт | Рекомендуется для |
|---------|---------|-------------------|
| Высокое | 2.5 Mbps | Длительное хранение, высокое качество |
| Среднее | 1.5 Mbps | Баланс качества и размера (по умолчанию) |
| Низкое | 0.8 Mbps | Длительная запись, экономия места |

### Форматы записи

- **Контейнер:** WebM
- **Видео кодек:** VP9 (или VP8 если VP9 не поддерживается)
- **Совместимость:** Все современные браузеры и видеоплееры

### Требования к браузеру

- ✅ Chrome/Edge 85+
- ✅ Firefox 80+
- ✅ Safari 14+ (частичная поддержка)
- ⚠️ Opera 71+

**Необходимые API:**
- MediaRecorder API
- Capture Stream API
- HLS.js (автоматически загружается)

## 🛠️ Устранение проблем

### Видео не загружается

**Проблема:** Не удаётся автоматически загрузить поток

**Решение:**
1. Используйте ручной метод получения URL (см. Шаг 1)
2. Проверьте, что URL содержит токен
3. Попробуйте открыть URL напрямую в браузере для проверки

### Запись не начинается

**Проблема:** Кнопка "Начать запись" неактивна

**Решение:**
1. Убедитесь, что видео воспроизводится
2. Проверьте, что браузер поддерживает MediaRecorder API
3. Нажмите "play" на видеоплеере вручную

### Токен не обновляется

**Проблема:** Видео останавливается после истечения токена

**Решение:**
1. Проверьте, что галочка "Автоматически обновлять токен" установлена
2. Используйте кнопку "Обновить токен вручную"
3. Проверьте журнал событий для диагностики
4. Возможно, API камеры изменился - обновите URL вручную

### CORS ошибки

**Проблема:** Ошибки Cross-Origin в консоли браузера

**Решение:**
1. Используйте локальный веб-сервер (см. Быстрый старт)
2. Или используйте расширение браузера для отключения CORS (только для тестирования!)

### Плохое качество записи

**Проблема:** Записанное видео низкого качества

**Решение:**
1. Выберите "Высокое" качество в настройках
2. Проверьте скорость интернет-соединения
3. Убедитесь, что исходный поток имеет хорошее качество

## 🔐 Безопасность и приватность

- ✅ Все операции выполняются локально в браузере
- ✅ Записи хранятся только в памяти браузера
- ✅ Токены не передаются третьим лицам
- ✅ Нет серверной части - полностью клиентское приложение
- ⚠️ Не храните токены в публичных местах

## 📝 API Endpoints (для разработчиков)

Приложение пытается получить stream URL из следующих endpoints:

```javascript
// Пробуемые URL паттерны
https://clients.apsny.camera/api/streams/{cameraId}
https://stream.apsny.camera/hls/{cameraId}/index.m3u8
https://clients.apsny.camera/streams/{cameraId}/playlist.m3u8
https://cdn.apsny.camera/live/{cameraId}/index.m3u8
```

Токен извлекается из параметров URL:
- `?token=...`
- `?auth=...`
- `?key=...`
