Журнал событий

Как это работает:

  1. Вставьте ссылку: Просто вставьте полную ссылку с apsny.camera (например: https://apsny.camera/?sukhum_chegem)
  2. Автоматическое извлечение: Backend автоматически получит stream URL и токен - ничего делать вручную не нужно!
  3. Мониторинг токена: Отслеживает время жизни токена и автоматически обновляет его перед истечением
  4. Непрерывная запись: Запись продолжается даже при обновлении токена - новые сегменты автоматически добавляются
  5. Скачивание: После остановки записи можно скачать видео в формате WebM

Особенности:

  • ✅ Полностью автоматическое извлечение stream URL и токена
  • ✅ Не нужно открывать DevTools и искать ссылки вручную
  • ✅ Автоматическое обновление токена без прерывания записи
  • ✅ Поддержка HLS потоков (.m3u8)
  • ✅ Мониторинг статуса соединения в реальном времени
  • ✅ Логирование всех событий
  • ✅ Множественные записи с одной камеры
  • ✅ Настройка качества записи

Требования:

  • Node.js 16+ установлен на компьютере
  • Запущен backend сервер: npm install && npm start
  • Современный браузер (Chrome, Firefox, Edge)
