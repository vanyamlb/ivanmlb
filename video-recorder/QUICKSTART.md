## 📖 Использование за 3 простых шага

### 1️⃣ Запустите приложение

**Windows:** Двойной клик на `start.bat`

**macOS/Linux:**
```bash
./start.sh
```

Вы увидите:
```
╔════════════════════════════════════════════════════════╗
║  ✅ ВСЁ ГОТОВО! Приложение запущено!                  ║
╚════════════════════════════════════════════════════════╝

📱 URL: http://localhost:3000
```

### 2️⃣ Скопируйте ссылку на камеру

Откройте https://apsny.camera/ и скопируйте ссылку:

```
https://apsny.camera/?sukhum_chegem
https://apsny.camera/?gagra_beach
https://apsny.camera/?pitsunda_embankment
```

Или используйте только ID:
```
sukhum_chegem
gagra_beach
pitsunda_embankment
```

### 3️⃣ Начните запись

1. В браузере (http://localhost:3000) вставьте ссылку
2. Нажмите **"Загрузить поток"** 🎥
3. Backend автоматически получит всё!
4. Нажмите **"Начать запись"** ⏺
5. Готово! 🎬

## ❓ Не работает?

### Проблема: "Node.js не найден"

**Решение:**
1. Установите Node.js с https://nodejs.org (версия 16+)
2. Перезапустите терминал
3. Попробуйте снова

### Проблема: "Порт 3000 занят"

**Решение:**
Скрипт автоматически освободит порт. Если не помогло:

**Windows:**
```cmd
netstat -ano | findstr :3000
taskkill /F /PID <номер_процесса>
```

**macOS/Linux:**
```bash
lsof -ti:3000 | xargs kill -9
```

### Проблема: "Браузер не открылся"

**Решение:**
Откройте вручную: http://localhost:3000

### Проблема: "Stream не загружается"

**Решение:**
1. Проверьте интернет-соединение
2. Убедитесь, что ссылка с apsny.camera корректная
3. Попробуйте другую камеру
4. Посмотрите логи в `server.log`
