# 🚀 Быстрый старт

## Запуск приложения (обязательно!)

### Шаг 1: Установка зависимостей

```bash
cd video-recorder
npm install
```

### Шаг 2: Запуск backend сервера

```bash
npm start
```

Вы должны увидеть:
```
╔══════════════════════════════════════════════════════╗
║   Apsny Camera Recorder - Backend Server            ║
║   Port: 3000                                         ║
║   Status: Running                                    ║
╚══════════════════════════════════════════════════════╝
```

### Шаг 3: Откройте браузер

Откройте: http://localhost:3000

## 🎯 Использование за 3 простых шага

### 1️⃣ Скопируйте ссылку на камеру

Просто откройте https://apsny.camera/ и скопируйте ссылку на нужную камеру.

Примеры ссылок:
```
https://apsny.camera/?sukhum_chegem
https://apsny.camera/?gagra_beach
https://apsny.camera/?pitsunda_embankment
```

Или используйте только ID:
```
sukhum_chegem
gagra_beach
pitsunda_embankment
```

### 2️⃣ Вставьте и загрузите

1. Вставьте скопированную ссылку (или только ID) в поле "Ссылка или ID Камеры"
2. Нажмите **"Загрузить поток"** 🎥

**Всё! Больше ничего делать не нужно!**

Backend автоматически:
- ✅ Извлечёт stream URL
- ✅ Получит токен доступа
- ✅ Настроит автоматическое обновление токена
- ✅ Запустит видеопоток

### 3️⃣ Записывайте!

1. Дождитесь начала воспроизведения видео
2. Нажмите красную кнопку **"Начать запись"** ⏺
3. Запись идёт! Токен обновляется автоматически
4. Остановите запись **⏹** когда нужно
5. Скачайте запись **⬇** в формате WebM

## 🔧 Устранение проблем

### Backend не запускается?

**Проблема:** Ошибка при `npm start`

**Решение:**
```bash
# Установите Node.js 16+ с nodejs.org
# Затем:
cd video-recorder
npm install
npm start
```

### "Backend сервер не запущен"?

**Проблема:** В браузере видно предупреждение

**Решение:**
1. Откройте терминал
2. Перейдите в папку `video-recorder`
3. Выполните `npm start`
4. Обновите страницу в браузере

### Видео не загружается?

**Проблема:** Поток не найден

**Решение:**
✅ Проверьте, что ссылка корректная (скопирована с apsny.camera)
✅ Попробуйте другую камеру
✅ Посмотрите журнал событий внизу страницы
✅ Проверьте логи backend в терминале

### Токен истёк во время записи?

**Проблема:** Запись прервалась

**Решение:**
✅ Убедитесь, что галочка "Автоматически обновлять токен" включена
✅ Проверьте, что backend сервер работает
✅ Попробуйте нажать "Обновить токен вручную"

## 💡 Полезные советы

### Для длинных записей:
```
1. Используйте качество "Низкое" для экономии места
2. Убедитесь, что галочка "Автоматически обновлять токен" включена
3. Проверяйте журнал событий - там видно все обновления токена
```

### Для лучшего качества:
```
1. Выберите качество "Высокое" (2.5 Mbps)
2. Убедитесь, что интернет-соединение стабильное
3. Закройте другие программы, использующие интернет
```

### Debugging:
```
1. Откройте консоль браузера (F12)
2. Смотрите логи backend в терминале
3. Проверьте раздел "Журнал событий" в приложении
```
