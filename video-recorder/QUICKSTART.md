# 🚀 Быстрый старт

## Запуск приложения

### Вариант 1: Python (самый простой)

```bash
cd video-recorder
python3 -m http.server 8000
```

Откройте браузер: http://localhost:8000

### Вариант 2: Прямое открытие

Просто откройте файл `index.html` в браузере (двойной клик)

---

## Первое использование за 3 шага

### 1️⃣ Получите Stream URL

1. Откройте https://clients.apsny.camera/
2. Нажмите F12 (DevTools) → вкладка Network
3. Введите в фильтр: `m3u8`
4. Выберите любую камеру
5. Скопируйте URL из Network requests

Пример URL:
```
https://stream.apsny.camera/hls/sukhum_chegem/index.m3u8?token=abc123...
```

### 2️⃣ Загрузите поток

Два способа:

**Автоматический:**
- Введите ID камеры: `sukhum_chegem`
- Нажмите "Загрузить поток"

**Ручной:**
- Вставьте полный URL в поле "Stream URL"

### 3️⃣ Записывайте!

1. Подождите, пока видео начнёт воспроизводиться
2. Нажмите красную кнопку "Начать запись" ⏺
3. Запись идёт! Токен обновляется автоматически
4. Остановите запись ⏹ когда нужно
5. Скачайте запись ⬇

## ⚡ Основные функции

| Функция | Описание |
|---------|----------|
| 🔄 Авто-обновление токена | Токен обновляется за 2 мин до истечения |
| ⏺ Запись | Непрерывная запись в WebM |
| 📊 Мониторинг | Отслеживание статуса в реальном времени |
| 💾 Качество | Выбор: Высокое/Среднее/Низкое |
| 📝 Журнал | Все события логируются |

## 🔧 Устранение проблем

### Видео не грузится?
✅ Проверьте URL в Network tab
✅ Убедитесь, что URL содержит токен
✅ Используйте локальный сервер

### Запись не начинается?
✅ Нажмите play на видео вручную
✅ Проверьте браузер (Chrome/Firefox лучше всего)

### Токен истёк?
✅ Включите "Автоматически обновлять токен"
✅ Или нажмите "Обновить токен вручную"

## 💡 Полезные советы

1. **Качество записи:** Начните со Среднего качества
2. **Длинные записи:** Используйте Низкое качество для экономии места
3. **Токен:** Галочка "Автоматически обновлять" должна быть включена
4. **Проблемы:** Смотрите журнал событий внизу страницы
